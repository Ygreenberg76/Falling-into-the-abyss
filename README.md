# Falling Into the Abyss

An interactive historical timeline concept in which the visitor scrolls downward through an abyss while a falling human figure reacts to scroll speed. Historical events appear along the walls; clicking one pauses the fall and opens a detail panel.

## Current status

This is the first interaction prototype.

- Scroll-driven falling-person animation
- Abyss / canyon visual
- Momentum, body rotation, motion lines and depth effects
- Clickable chronological event markers
- Event detail and statistics panel
- Responsive mobile layout
- Keyboard navigation
- Reduced-motion support
- Historical entries are explicitly marked as drafts until fully researched

## Run locally

Open `index.html` in a modern browser.

## Historical methodology

The final research phase should use primary documents and reputable academic/archival sources, distinguish different actors accurately, identify disputed casualty figures, and avoid presenting uncertain ancient figures as equivalent to well-documented modern statistics.
